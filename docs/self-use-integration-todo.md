## 需要改写的上游行为

1. **不能用回复正文作事件去重身份。** 本地 listener.py 的 jid 目前包含 final。集成时依 F01 迁移到稳定源事件 ID；同 ID 异内容不能通过换 ID 默默吞掉。
2. **不能照搬 shell exit=1 且有 stdout 就视为正常。** context-mode 的 exit-classify.ts 有这个泛化规则。B07 必须按工具语义保留真实失败。
3. **不能把截断 JSON 当协议 JSON。** context-mode truncateJSON 明确只适合展示。B05 在结构内选择字段并最终完整序列化。
4. **不能继承“固定 ≤2 KB 恢复包”的说法。** 当前 context-mode snapshot.ts 忽略 maxBytes；消息展示也会缩略。D01/D02/D05 明确保留预算和损失语义。
5. **不能静默恢复同项目最新快照。** context-mode 的 resume fallback 会领取其他会话最近未消费快照。E06/I02 保留精确身份与明确选择。
6. **不能为了限制开销静默丢弃队列。** ai-memory spool 有容量策略；你的既有要求保留待评估队列。F07 使用背压、延期和可见积压。
7. **不能把检索/上下文热度当用户授权。** 个人偏好、历史程序和工具结果不能授予新权限；当前用户指令和项目范围优先。
8. **不能用数据库租约替代 workspace 协作权。** 领取记忆、送达 packet、逐项对齐和实际写入权是不同状态。
9. **不能用“有原文”证明“模型已回读”。** 需要记录实际取用和真实下一步；H03/I08 分开度量。
10. **不能仅靠英文 Porter/trigram 支持所有中文检索。** C04 对中文短词/标识符保留精确通道，复用现有多语检索。
11. **不能把派生搜索库恢复策略套到任务库。** Rail 的任务、owner、pending action 等运行状态不可通过删库重建来“恢复”。
12. **不能把子进程叫作完整 OS 权限沙箱。** 新工具继续遵守宿主已有执行和访问范围；本轮不规划一套新的执行权限系统。
13. **不能凭设计文档声称代码已交付。** I07 明确是设计启发；其他项以当前固定版本源码及实际集成行为为准。
14. **不能把 source+title 当不可变证据身份。** Rail 继续使用 task/artifact/revision/span，避免融合检索误合并同名材料。

## 不列为本轮自用建设的功能

下列能力已评估其相关性，但它们不能直接改善当前单机小 demo，或已有更轻的入口，故不扩成实施任务：

- 多用户账号、SSO、RBAC、组织审计、团队消息和跨组织/A2A 协作。
- 公网托管、云同步服务、准入 webhook、外部分析上传和对外运营界面。
- 同时支持所有客户端或十二种执行语言；先服务实际使用的 Codex/Claude 与已有运行时。
- 重写 Rust 核心、另建向量服务、另起默认监听器，或整仓安装 ai-memory 代替已有 main 服务。
- 自动 Git 远端备份/推送、自动发布、自动新建聊天；需要这些动作时按明确请求处理。
- 自动长时间 dream、固定会话数归纳、新增默认定时任务；G04 是显式入口并复用现有预算。
- 固定搜索第 N 次硬封禁、按年龄清空当前会话、未经保留核对的 TTL 删除。
- 自动修改 AGENTS.md/CLAUDE.md、自动把助手推断提升为用户偏好。
- 修改其他客户端的私有会话存储，或复制隐藏推理/系统开发者指令。
