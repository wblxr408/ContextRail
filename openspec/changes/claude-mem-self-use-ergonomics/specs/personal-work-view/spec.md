# Spec Delta

## Purpose

为单机使用者提供可打开的任务、来源与交付结果视图，把已有状态和回读能力组织成日常入口。界面区分来源声明、实际证据、人工查看和连接状态，使用户能够找到工作而不引入第二套任务权威或自动执行流程。

## Delivery Scope

原 A–D 首批仅要求交付物在当前聊天、CLI/MCP 可发现。用户现已显式启用完整本地界面：任务总览、SessionDetailPage、人工已查看和页面连接/来源状态要求生效；更多客户端仍后置。设置只维护已有项目接线，不改变原账号或新建记忆/采集服务。

## ADDED Requirements

### Requirement: 交付物入口独立于完整界面
系统 SHALL 在现有任务入口提供交付物列表、详情、来源与可打开的路径或链接，不要求先启动完整任务页面或启用人工查看功能。

#### Scenario: 未启用完整页面仍可找产物
- **WHEN** 用户在当前聊天、CLI 或 MCP 查询已登记任务的交付物且完整页面未启用
- **THEN** 系统返回有界列表及所选产物的精确身份、来源和可打开链接，缺失或改变有独立说明


### Requirement: 任务总览投影
当完整界面显式启用时，系统 SHALL 按明确项目、worktree 和任务身份显示已有状态、来源、下一步及缺口，推断和未知必须可辨。

#### Scenario: 同名任务分别显示
- **WHEN** 不同 worktree 中存在同名任务
- **THEN** 视图分别显示其身份和来源，不按名称或同目录线索自动合并

#### Scenario: 只有完成声明
- **WHEN** 来源只有助手完成声明而没有匹配结果证据
- **THEN** 视图显示声明性质，不将其提升为已验证完成

### Requirement: 来源详情与精确恢复导航
系统 SHALL 从现有原生入口或已启用的任务卡链接到现有时间线、来源窗口和精确恢复预览，普通浏览不得领取任务或转移写权。

#### Scenario: 打开历史恢复点
- **WHEN** 用户打开已失效的历史快照卡片
- **THEN** 系统显示历史状态与具体缺口，不以当前快照静默替换，不改变租约

### Requirement: 交付物关联
系统 SHALL 为显式登记的交付物保留任务、来源、版本和位置，并区分当前文件、历史材料与外部发布声明。

#### Scenario: 产物位置失效
- **WHEN** 已登记文件已移动、缺失或改变版本
- **THEN** 系统保留原登记来源并显示失效原因，不展示为空任务或伪造当前副本

#### Scenario: 仅观察到外部链接
- **WHEN** 来源只包含 PR 或提交链接而没有发布成功回执
- **THEN** 视图显示有出处的链接，不据此声称本轮已发布

### Requirement: 人工已查看与版本绑定
当完整界面的人工查看功能显式启用时，系统 SHALL 仅依据本地用户显式操作记录已查看状态，并将该状态绑定到明确任务与产物版本；它不得替代验收或执行授权。

#### Scenario: 查看后结果改变
- **WHEN** 用户标记已查看后对应任务要求或产物版本发生变化
- **THEN** 新版本重新显示待查看，旧版本的人工记录仍可追溯

#### Scenario: 保存查看状态失败
- **WHEN** 用户点击已查看而该元数据无法保存
- **THEN** 界面说明失败，不冒称已保存，不修改任务完成事实

### Requirement: 连接与来源新鲜度分离
当完整界面显式启用时，系统 SHALL 分别显示传输连接、来源可读性和最后数据接收时间，断线时保留最后已知视图并标明陈旧。

#### Scenario: 页面在线但来源不可读
- **WHEN** 页面连接存在但当前保存状态读取失败
- **THEN** 显示来源不可用及旧数据时间，不把连接成功解释为任务或 Agent 正在运行

### Requirement: 界面按需启用
系统 SHALL 在用户显式启用的本地入口中提供视图，刷新只读取既有状态，不新增模型归纳、默认采集器或外部发送动作。

#### Scenario: 关闭页面
- **WHEN** 用户关闭个人任务页面
- **THEN** 原任务、原记忆服务和已保存证据继续保留，页面关闭不触发任务取消或接管

#### Scenario: Windows PowerShell 原生启动
- **WHEN** 用户使用 Windows PowerShell 5.1 在含中文路径的已接入项目运行启动脚本
- **THEN** 脚本正确读取 UTF-8 配置，将确切 registry、端口和空闲参数传给后台进程，启动或复用原任务工作台

#### Scenario: 指定视觉参考与产品标识
- **WHEN** 用户指定 MedPanel 参考及已生成的 ContextRail Logo
- **THEN** 三页共用金奶油纸张主题、文件夹式导航和产品图标；桌面工作台六面板在窄屏堆叠，原始来源、未知状态与可访问标签继续明确


#### Scenario: 固定的共用主导航
- **WHEN** 用户在工作台、My Work、记忆档案间切换或滚动内容
- **THEN** 同一视口中的产品标识与三个导航页签保持相同位置和尺寸，当前页签被标明，原页面工具仍可使用

#### Scenario: 桌面一屏工作台
- **WHEN** 用户以至少1051px宽、680px高的桌面视口打开工作台
- **THEN** 六面板及页尾在视口内呈现，长列表和展开详情可在所属面板中滚动，较窄或较矮窗口允许自然文档滚动

#### Scenario: 多栏记忆档案
- **WHEN** 用户浏览记忆时间线或会话卡片
- **THEN** 宽屏三列、中屏双列、窄屏单列；页标题与分页提示独立于卡片网格，条目逐行按原顺序显示
